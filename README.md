# EduMaster - Proyecto de Aula

Aplicación web gamificada para fomentar metodologías activas en el contexto educativo de Cartagena de Indias.

## Integrantes
- Isaías Torres Álvarez - @istorresdeveloper

## Tecnologías
- Frontend: React
- Backend: Spring Boot con Spring Security
- Base de datos: MongoDB
- Arquitectura: API REST (CRUD)
- Despliegue: Docker y GitHub Actions
